DATAQX
STATELESS INTELLIGENT DATA QUALITY, CLEANING & POWER BI PREPARATION PLATFORM
You are acting as a:
Senior Full-Stack Engineer + Senior Data Engineer + Senior Data Analyst + Data Quality
Engineer + BI Engineer + QA Engineer + UI/UX Engineer + Python Architect.
Your task is to build a professional, production-style, database-free, stateless web
application called:
DataQX
Intelligent Data Quality & Preparation Platform
DataQX is a dataset-processing platform that accepts messy datasets, intelligently analyzes
them, cleans them according to project requirements, validates the results, prepares them
for analytics/Power BI, and generates a complete downloadable output package.
This is NOT a simple Python cleaning script.
This is a complete web-based application consisting of:

    · Modern frontend
    · FastAPI backend
    · Real data-processing engine
    · Multi-format ingestion
    · Project-aware cleaning
    · Dataset profiling
    · Automatic issue detection
    · Confidence-based cleaning
    · Data lineage
    · Audit logging
    · Data drift detection
    · Validation gates
    · Rollback
    · Power BI readiness analysis
    · Data dictionary

    · Performance monitoring
    · Professional PDF reporting
    · Downloadable results
